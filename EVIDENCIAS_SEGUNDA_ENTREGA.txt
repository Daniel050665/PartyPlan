9. COMUNICACION PADRE-HIJO: input(), output(), emit(), $event
--------------------------------------------------------------------------------
Funcionalidad: SELECCIONAR Y EDITAR UN USUARIO.
  PADRE: F/pages/usuarios.page.ts / .html
  HIJO:  F/pages/usuario-form.component.ts / .html
Paso a paso:
  1. En la tabla de Usuarios se pulsa el lapiz -> abrirEditar(usuario)
     F/pages/usuarios.page.ts:121 guarda usuarioSeleccionado = usuario.
  2. El padre se lo envia al hijo:
     F/pages/usuarios.page.html  <app-usuario-form [usuario]="usuarioSeleccionado" ...>
  3. input(): el hijo lo recibe
     F/pages/usuario-form.component.ts:32  usuario = input<Usuario | null>(null);
     y en ngOnInit llena el formulario con esos datos.
  4. output(): el hijo declara el evento
     F/pages/usuario-form.component.ts:36  guardar = output<Usuario>();
  5. emit(): al pulsar Guardar el hijo envia el usuario modificado
     F/pages/usuario-form.component.ts:113 this.guardar.emit(usuarioModificado);
  6. $event: el padre lo recibe
     F/pages/usuarios.page.html:88  (guardar)="guardarUsuario($event)"
     F/pages/usuarios.page.ts:134   guardarUsuario(usuario: Usuario) -> PUT al backend
Mostrar: Usuarios -> lapiz de un cliente -> cambiar el nombre -> Guardar ->
la tabla se actualiza.
(Tambien usan input()/output(): F/shared/modal.component.ts,
 icon.component.ts y bar-list.component.ts)
